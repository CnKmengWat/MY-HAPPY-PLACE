# MY HAPPY PLACE — Android starter project

នេះជា Android Studio starter project សម្រាប់កម្មវិធី Social Chat ដែលមានរចនាបថផ្ទាល់ខ្លួន ស្រដៀងគំនិតកម្មវិធី social chat។

## អ្វីដែលមានរួច
- Home screen
- Soul Match demo screen
- Voice Party room list (UI demo)
- Chat list និង chat screen (local demo)
- Profile screen
- Bottom navigation

## របៀបបើក
1. ដំឡើង Android Studio (version ដែលគាំទ្រ Android Gradle Plugin 8.7.3)។
2. Extract ZIP ហើយបើក folder `MY_HAPPY_PLACE` ក្នុង Android Studio។
3. រង់ចាំ Gradle Sync។
4. ចុច Run ដើម្បីដំណើរការលើ Android Emulator ឬទូរស័ព្ទ។
5. ដើម្បីបង្កើត APK៖ Build > Build Bundle(s) / APK(s) > Build APK(s)។

## ចំណាំសំខាន់
នេះជាគម្រោង UI prototype មិនទាន់ជាកម្មវិធី online ពេញលេញទេ។ Login, Firebase database, real-time messaging, voice rooms/WebRTC, uploads, notifications, payments និង VIP ត្រូវការភ្ជាប់ backend និងកំណត់ credentials ផ្ទាល់ខ្លួន មុនដាក់ឱ្យអ្នកប្រើប្រាស់ពិត។
